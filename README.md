# AST - Школа вина

Статическая вёрстка на Vite без фреймворков. Документация к вёрстке и JS-модулям для интеграции в Bitrix вынесена в технические страницы
раздела `/code/`. Они открываются на запущенном проекте (`npm run dev`) или в собранном `dist/code/`.

## Техническая документация

- [Быстрый старт](src/code/index.html) (`/code/`): установка, сборка, перенос в Bitrix, функции из разметки
- [Карта иконок сайта](src/code/icons/index.html) (`/code/icons/`)
- [JS модули и плагины](src/code/js/index.html) (`/code/js/`)
- [Формы и JS валидация](src/code/forms/index.html) (`/code/forms/`)
- [Яндекс карты](src/code/maps/index.html) (`/code/maps/`)
- [Попапы](src/code/popups/index.html) (`/code/popups/`)
- [Слайдеры](src/code/sliders/index.html) (`/code/sliders/`)
- [Табы](src/code/tabs/index.html) (`/code/tabs/`)
- [Аккордеоны](src/code/accordeons/index.html) (`/code/accordeons/`)
