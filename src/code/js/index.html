    Вся логика подключается одним файлом assets/js/scripts.js, он сам импортирует остальные модули. Как подключить его в шаблон, описано в Быстром старте. Каждый модуль проверяет, есть ли на странице его элементы, и если нет, ничего не делает. Поэтому все модули можно оставлять подключёнными на всех страницах.

    Галерея картинок

    Клик по картинке открывает её на весь экран. Можно листать стрелками, свайпом и клавиатурой, увеличивать двумя пальцами. Блок с data-gallery объединяет картинки в одну галерею. Картинке нужен data-source с адресом большой версии. Картинки без data-source в галерею не попадают.

    <div class="swiper" data-gallery>
  <div class="swiper-wrapper">
    <div class="swiper-slide">
      <img src="<?=$photo['SMALL']?>" data-source="<?=$photo['BIG']?>" alt="<?=$photo['ALT']?>" />
    </div>
  </div>
</div>

    • Листание идёт в пределах своего блока data-gallery.

    • Обработчик клика один на весь документ, поэтому картинки, добавленные AJAX-ом или кнопкой «Показать ещё», работают без повторной инициализации.

    Календарь

    Обычное поле type="date" само превращается в календарь, атрибуты добавлять не нужно. required работает как обычно.

    <label class="label">
  <span class="label-text">Дата рождения</span>
  <input type="date" name="birthday" class="input" value="1990-05-21" required />
</label>

    Посетитель видит дату как 21.05.1990, а на сервер под тем же name уходит 1990-05-21. Модуль переносит name на скрытое поле, а у видимого поля name убирает. Значение по умолчанию задаётся в value в формате ГГГГ-ММ-ДД.

    «Читать полностью»

    Один блок текста

    data-read-more="N" обрезает текст до N строк. Кнопка «Читать полностью» появляется, только если текст действительно не помещается.

    <p class="text" data-read-more="6"><?=$review['TEXT']?></p>

    Несколько абзацев

    data-read-more-group="N" на обёртке: лимит в N строк считается на все абзацы <p> внутри вместе. Абзацы ниже лимита скрываются до раскрытия.

    <div class="content" data-read-more-group="10">
  <?=$arResult['DETAIL_TEXT']?>
</div>

    Абзацы должны быть прямыми потомками обёртки.

    Копирование в буфер

    Кнопка data-copy-to-buffer копирует текст ближайшего блока data-copy и показывает уведомление «Скопировано в буфер обмена».

    <div class="promo-code">
  <span data-copy><?=$arResult['PROMO_CODE']?></span>
  <button type="button" data-copy-to-buffer aria-label="Скопировать промокод">
    <svg width="24" height="24"><use href="<?=SITE_TEMPLATE_PATH?>/assets/img/sprite.svg#copy"></use></svg>
  </button>
</div>

    Звёзды рейтинга

    data-rating с оценкой от 0 до 5, можно дробной. Звёзды дорисовываются сами, в том числе в разметке, добавленной AJAX-ом. Текст внутри блока скрыт визуально и нужен для экранных дикторов.

    <div class="stars" data-rating="4.5">Рейтинг 4.5 из 5</div>

    Заказ сертификата

    Данные формы заказа сертификата сохраняются в localStorage под ключом certificate-order, чтобы посетитель не потерял их при перезагрузке. После успешной оплаты их нужно очистить, например на странице «Спасибо за заказ»:

    localStorage.removeItem('certificate-order');

    Шаги заказа переключает функция toCertStep(popupId, group): она проверяет поля группы data-cert-group и открывает попап следующего шага.

    Как добавить свой модуль

    1. Создать файл в assets/js/modules/ с функцией инициализации. Если нужных элементов на странице нет, сразу выходить.

    2. Импортировать её в scripts.js и вызвать внутри обработчика DOMContentLoaded.

    // modules/my-module.js
export const initMyModule = () => {
  const blocks = document.querySelectorAll('[data-my-module]');
  if (!blocks.length) return;

  // ...
};

    Пути к файлам внутри модуля считать от самого модуля, а не от корня сайта. Тогда они не сломаются, где бы ни лежал шаблон:

    const spriteUrl = new URL('../../img/sprite.svg', import.meta.url).href;
