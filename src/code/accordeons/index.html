    • Аккордеоны

    Аккордеон это блок с data-accordeon. Внутри шапка data-accordeon-head и раскрывающаяся часть data-accordeon-body. Клик по шапке раскрывает и сворачивает тело с плавной анимацией высоты.

    <div class="faq-accordeon" data-accordeon data-accordeon-group="faq">
                <div class="faq-head" data-accordeon-head>
                  <p class="title title--18">Нужны ли предварительные знания?</p>
                  <button type="button" aria-expanded="false" aria-label="Развернуть"></button>
                </div>
                <div data-accordeon-body>
                  <div class="faq-body">
                    <p class="text">Нет, курс начинается с нуля.</p>
                  </div>
                </div>
              </div>

    Отступы и фон ставьте на внутренний блок (.faq-body), а не на сам data-accordeon-body: у него JS меняет высоту, и отступы на нём ломают анимацию.

    Открыт при загрузке

    Класс open на data-accordeon раскрывает аккордеон сразу. Так можно открыть, например, первый вопрос или текущий модуль курса.

    <div class="faq-accordeon open" data-accordeon>...</div>

    Атрибуты

    АтрибутЧто делает
    data-accordeon-group="имя"в группе одновременно открыт только один аккордеон: при открытии одного остальные сворачиваются
    data-init="mobil"аккордеон работает только до 767px. На больших экранах тело всегда раскрыто. Так сделаны колонки меню в подвале
    data-init="tablet"то же, но до 1279px
    data-accordeon-arrow-onlyраскрывается только кнопкой в шапке, клик по остальной шапке ничего не делает

    Поведение

    • Ссылка внутри шапки ведёт по своему адресу и аккордеон не переключает. Так у модуля курса название может быть ссылкой на страницу модуля.

    • Кнопке в шапке модуль сам ставит aria-expanded по состоянию аккордеона.

    • Аккордеоны можно вкладывать друг в друга.

    • Классы open у аккордеона и у шапки ставит модуль, по ним стили поворачивают стрелку.

    Аккордеоны ищутся один раз при загрузке страницы. Аккордеоны из разметки, вставленной AJAX-ом, корректно работать не будут.
