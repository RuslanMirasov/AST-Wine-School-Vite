    • Табы

    Группа табов это блок с data-tabs. Внутри кнопки с data-tab-target и панели с data-tab. Кнопка открывает панель с тем же именем. Активные кнопка и панель получают класс active.

    <div data-tabs="orders">
                <ul class="search-navigation">
                  <li><button type="button" class="search-navigation__btn active" data-tab-target="current">Текущие</button></li>
                  <li><button type="button" class="search-navigation__btn" data-tab-target="archive">Архив</button></li>
                </ul>

                <div data-tab="current">Текущие заказы</div>
                <div data-tab="archive">Архив заказов</div>
              </div>

    Какой таб открыт при загрузке

    Открыта панель активной кнопки, то есть кнопки с классом active. Если активной кнопки нет, открыта панель с классом active, а если нет и её, то первая панель. Чтобы при загрузке открыть другой таб, достаточно поставить active на нужную кнопку на сервере.

    <button type="button" class="search-navigation__btn<?=$arResult['TAB'] === 'archive' ? ' active' : ''?>" data-tab-target="archive">Архив</button>

    Атрибуты

    АтрибутГдеЧто делает
    data-tabs="имя"на обёртке группыгруппа табов. Имя нужно, чтобы переключать таб из кода
    data-tab-target="имя"на кнопкеоткрывает панель с таким же data-tab
    data-tab="имя"на панелисодержимое таба. Несколько панелей с одинаковым именем открываются вместе
    data-unanimatedна обёртке группыпереключение без плавного появления

    Вложенные группы

    Группы можно вкладывать друг в друга: каждая кнопка управляет только панелями своей ближайшей группы.

    Табы в формах

    Табы используются не только для переключения контента, но и для переключения набора полей в одной форме. Главное правило: поля из скрытых табов в форму не попадают.

    • Поля внутри скрытой панели получают disabled.

    • Отключённые поля не проверяются валидацией: пустое обязательное поле в скрытом табе не помешает отправке.

    • Отключённые поля не уходят на сервер: в $_POST придут только общие поля и поля открытого таба.

    • При переключении таба поля открытой панели снова включаются, а поля закрытой отключаются.

    • Поля, у которых disabled стоит в разметке изначально, модуль не трогает и не включает.

    Где используется

    ГдеЧто переключается
    Оформление заказа, cart/checkout/физическое и юридическое лицо. Общие поля (ФИО, почта, телефон) отправляются всегда. Дата рождения только у физлица. Наименование, ИНН, КПП и адрес только у юрлица
    Подарочный сертификат, gift-certificates/электронный, печатный и корпоративный сертификат, получатель «другу» или «себе». Здесь работает свой модуль certificat-order.js, но по тому же принципу: поля неактивного варианта получают disabled и не отправляются

    Пример: физическое и юридическое лицо

    Группа data-tabs охватывает и кнопки, и форму. Панели data-tab могут быть любым элементом внутри формы: <label>, <fieldset>, подсказкой. Всё, что вне панелей, отправляется всегда.

    <section data-tabs="entity" data-unanimated>
                <div class="buttons">
                  <button type="button" class="button button--tab active" data-tab-target="individual"><span>Физическое лицо</span></button>
                  <button type="button" class="button button--tab" data-tab-target="legal-entity"><span>Юридическое лицо</span></button>
                </div>

                <form data-form novalidate action="" method="post">
                  <!-- тип покупателя: в каждой панели своё скрытое поле, на сервер придёт только одно -->
                  <input type="hidden" name="person_type" value="individual" data-tab="individual" />
                  <input type="hidden" name="person_type" value="legal" data-tab="legal-entity" />

                  <!-- общие поля, отправляются всегда -->
                  <label class="label">
                    <span class="label-text">Электронная почта *</span>
                    <input type="email" name="email" class="input" required />
                  </label>

                  <!-- только физическое лицо -->
                  <label class="label" data-tab="individual">
                    <span class="label-text">Дата рождения *</span>
                    <input type="date" name="birthday" class="input" required />
                  </label>

                  <!-- только юридическое лицо -->
                  <fieldset class="col--2" data-tab="legal-entity">
                    <label class="label">
                      <span class="label-text">ИНН *</span>
                      <input type="text" name="inn" class="input" data-rule="inn" data-digits maxlength="12" required />
                    </label>
                    <label class="label">
                      <span class="label-text">КПП *</span>
                      <input type="text" name="kpp" class="input" data-rule="kpp" data-digits maxlength="9" required />
                    </label>
                  </fieldset>

                  <button type="submit" class="button"><span>Оформить заказ</span></button>
                </form>
              </section>

    На сервере тип покупателя удобно определять по скрытому полю person_type: так не нужно гадать по набору пришедших полей.

    <?php
              $isLegal = $request->getPost('person_type') === 'legal';

              if ($isLegal) {
                $inn = $request->getPost('inn');
                $kpp = $request->getPost('kpp');
              } else {
                $birthday = $request->getPost('birthday'); // формат ГГГГ-ММ-ДД
              }

    Если поле должно отправляться при любом выбранном табе, его нужно вынести за пределы панелей data-tab. Чтобы при повторном показе формы после ошибки открылся нужный таб, поставьте класс active на его кнопку на сервере, как описано выше.

    Переключение из кода

    openTab('orders', 'archive');

    Первый аргумент имя группы из data-tabs, второй имя таба. Функция доступна глобально.

    Табы ищутся один раз при загрузке страницы. Кнопки группы, вставленной AJAX-ом, работать не будут, но openTab для такой группы сработает.
